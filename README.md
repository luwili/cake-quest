# Cake Quest

Секретный рецепт праздничного торта для мамы.

Интерактивный браузерный квест для дошкольников. Он работает на GitHub Pages без сборки, сторонних библиотек, изображений и аудиофайлов.

## В квесте

- пять заданий: тень мешочка с мукой, голос курицы, лишний предмет, двигательная пауза и пазл с клубникой;
- корзинка с мукой, яйцами, молоком, маслом и ягодами;
- синтезированные звуки курицы, сигнал успеха и ритмичная музыка для разминки;
- праздничный торт и поле, куда воспитатель вписывает место с открытками или поделками;
- адаптация для телефонов и клавиатуры, поддержка настройки уменьшения анимации.

## Запуск

Откройте файл index.html в браузере или запустите локальный сервер командой python3 -m http.server 8000. Затем откройте http://localhost:8000.

## Публикация

Каждое обновление ветки main автоматически публикуется GitHub Actions на GitHub Pages.
